# Second Tasks - SWAPI

### 1. Филмова статистика

Направете приложение, което зарежда всички филми и извежда статистика за всеки филм:

- заглавие
- година на издаване
- режисьор
- брой персонажи
- брой планети
- брой космически кораби
- брой превозни средства
- брой раси

След това:

- сортирайте филмите по брой персонажи;
- намерете филма с най-много персонажи;
- изведете средния брой персонажи на филм.

Тук студентите трябва да работят с вложени масиви и да разбират структурата на response-а.

### 2. „Кой е най-свързаният персонаж?“

```
име
брой филми
брой starships
брой vehicles
брой species
```

След това изведете:

- топ 10 персонажа по брой участия във филми;
- персонажа с най-много космически кораби;
- персонажа с най-много превозни средства.

Допълнително условие: резултатите да могат да се сортират по всяка от тези характеристики.

### 3. Explorer с динамично зареждане на свързани данни

Направете интерфейс, в който се показват всички персонажи.

При натискане върху персонаж:

1. зареждате неговите данни;
2. зареждате неговата планета;
3. зареждате species;
4. зареждате филмите му;
5. зареждате starships;
6. зареждате vehicles.

Идеята е да не използват предварително заредените всички данни, а да използват URL-ите от response-а за последващи заявки.

Това е добра задача за `Promise.all()`.

### 5. Character Search с debounce

Направете поле:

```
Search character...
```

Докато потребителят пише, приложението да търси персонажи.

Изисквания:

- да не се прави заявка при всяко натискане на клавиш;
- използвайте `debounce`, например 500 ms;
- показвайте loading state;
- обработвайте грешки;
- при празно поле да се показва началното състояние;
- резултатите да се показват като карти.

Тук вече задачата проверява не само API, а и правилно управление на async операции.

### 8. „Кой филм включва тези персонажи?“

Потребителят избира 2 или 3 персонажа.

Пример:

```
Luke Skywalker
Han Solo
Chewbacca
```

Приложението трябва да намери филмите, в които участват всички избрани персонажи.

Логиката трябва да е:

```
Films(Luke)
INTERSECT
Films(Han)
INTERSECT
Films(Chewbacca)
```

След това покажете:

```
A New Hope
The Empire Strikes Back
Return of the Jedi
...
```

Това вече е доста добра задача за работа с масиви, `filter`, `map`, `some`, `every`, `includes` и асинхронни заявки.

### 10. Финална задача: Star Wars Explorer

Направете малко SPA приложение „Star Wars Explorer“.

Да има меню:

```
Characters
Planets
Films
Starships
Vehicles
Species
```

При избор на категория:

1. зареждат се данните от API;
2. показват се в таблица или cards;
3. има search;
4. има sorting;
5. има filtering, където има смисъл;
6. при избор на елемент се отваря detail view;
7. detail view зарежда свързаните ресурси;
8. има loading state;
9. има error state;
10. има бутон Back.

Допълнителни условия:

- да няма дублиран код между различните категории;
- да се използва общ API service;
- да се използват reusable компоненти;
- да няма hardcoded API резултати;
- да се използват `async/await`;
- да се обработват случаи като `unknown`, `n/a` и празни масиви.
